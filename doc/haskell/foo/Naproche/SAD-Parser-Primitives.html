Primitive Token operations

tokenPrim :: (Token -> Maybe a) -> Parser st a Source #

Parse the current token or return an EmptyFail if the input is empty, eof or the supplied test functions returns Nothing.

tokenGuard :: (Token -> Bool) -> Parser st a -> Parser st a Source #

tokenGuard test p parses the current token using p only if the token passes the predicate test. Does not produce particularly useful error messages.

Parse the end of input

token :: Text -> Parser st () Source #

token tok succeeds iff the current token is equal to tok. Consumes the token.

token' :: Text -> Parser st () Source #

Case-insensitive version of token. The argument is assumed to be in folded case.

tokenPos' :: Text -> Parser st T Source #

A version of token' that returns the position of the token instead of ().

tokenOf :: [Text] -> Parser st () Source #

tokenOf toks succeeds iff the current token is an element of toks. Consumes the token.

tokenOf' :: [Text] -> Parser st () Source #

Case-insensitive version of tokenOf. All arguments are assumed to be in folded case.

tokenSeq :: [Text] -> Parser st () Source #

A sequence of tokens.

tokenSeq' :: [Text] -> Parser st () Source #

Case-insensitive version of tokenSeq. All arguments are assumed to be in folded case.

tokenSeqOf :: [[Text]] -> Parser st () Source #

tokenSeqOf tokSeqs succeeds iff one of the token sequences in tokSeq can be consumed.

tokenSeqOf' :: [[Text]] -> Parser st () Source #

Case-insensitive version of tokenSeqOf. All arguments are assumed to be in folded case.

symbol :: Text -> Parser st () Source #

Check if the next tokens are the (case-sensitive) characters of the input string. Useful for parsing symbols.
