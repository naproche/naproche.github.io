Parse one or more as interleaved by seps keeping all intermediary results.

Parse zero or more as interleaved by seps keeping all intermediary results.

sepByLL1 :: Parser st a -> Parser st sep -> Parser st [a] Source #

Same as sepBy but keep only the largest result.

opt :: a -> Parser st a -> Parser st a Source #

opt x p runs both p and x and combines their errors and results.

optLL1 :: a -> Parser st a -> Parser st a Source #

optLL1 x p will run p; if p fails without consuming any input it will return x.

optLLx :: a -> Parser st a -> Parser st a Source #

optLLx x p will try p; if p fails it will return x.

chain :: Parser st a -> Parser st [a] Source #

Run the parser as often as possible keeping all intermediary results.

chainLL1 :: Parser st a -> Parser st [a] Source #

Run the parser as often as possible keeping only the longest result.

enclosed :: Text -> Text -> Parser st a -> Parser st (Range, a) Source #

enclosed begin end p parses begin, followed by p, followed by end, returning the result of p and its range.
