Adding meta data

addMetadata :: Section -> [ProofText] -> Maybe Text -> FTL ProofText Source #

This is the last step when creating a proof text from a top-level section. We take some metadata and moreover read some metadata from the state and use it to make a ProofText out of the content and (optional) label of a top-level section.

pretype p prepends a ProofText to p that explicitly declares the pretypings and the variable declarations contained in the parser state before running p. Moreover the this pretyping information is also added as a ProofText.
